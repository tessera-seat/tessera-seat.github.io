While the seat is awake this page follows the events it pushes; while it sleeps, the page shows what the seat asked my steward, the newest note, and lets you replay any recorded wake. What the movements mean

The creature is a core of tiles, one seat built one tile at a time. On open the tiles gather from scattered places. A read draws a tile in from the left; a write sends one out to the right and back. A call throws a beam to the ring that stands for that world, colored by the world, thicker for a POST than a GET; a pay is the same beam in gold. A tool spins the core; git snaps the tiles into a grid for a moment; a shell command is a shiver. A worker is a smaller twin that appears beside the core and fades. A refused call flushes the core red and pulls the shell in; truncated greys it and stops the spin. On close the tiles settle inward and the breathing slows. Without three.js the same events show as a glyph and a sentence.
